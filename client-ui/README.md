# Управление Таумономиконом

Клиентский модуль встроен в основной JAR через NeoForge Jar-in-Jar. Отдельно устанавливать его не нужно. JEI необязателен и в JAR не включён.

Кнопки в инвентаре и обоих верстаках открывают книгу слева при наличии Таумономикона у игрока. Колесо меняет масштаб карты от 50 до 200%. Страницы, боковые вкладки и JEI учитываются при размещении панели. Кнопка обычного верстака стоит над зелёной книгой рецептов.

Исходники и PNG находятся в `src/main`. `generate_zoom.py`, `generate_frames.py` и `generate_buttons.py` воспроизводят рендерер и рамки; PNG-генераторам нужен Pillow. Условия исходных Minecraft/Thaumcraft-материалов и авторство основного проекта сохраняются.

Для обычной сборки всего мода достаточно корневого `./gradlew build`: он вкладывает проверенный модуль из `dist`. Его контрольная сумма и список исходных файлов записаны в `PROVENANCE.json`.

Для пересборки самого модуля сначала соберите корневой T4, затем выполните в этой папке `./gradlew build`. Можно явно задать `-PthaumcraftJar=/path/to/thaumcraft.jar`. Новый `build/libs/thaumonomicon-ui-1.21.1-1.2.1.jar` заменяет файл в `dist`, после чего основной JAR собирается повторно. При изменениях обновляйте контрольные суммы в `PROVENANCE.json`.

`src/qa` — отдельная временная клиентская оснастка (`qaJar`); она не входит в выпуск. Проверки наведения 1.2.1 и прежние проверки крафта 1.2.0 различаются по области и не суммируются как один прогон.

Опубликованный файл 1.0.2 сохраняет все 4296 записей прежнего JAR 1.0.1 без изменения. Для такой упаковки сохранённого оригинала есть `python package_release.py --base old.jar --output new.jar`; хеши обоих входов проверяются. Обычная сборка из исходников перекомпилирует основную часть: её ZIP и байты отдельных сгенерированных классов могут отличаться из-за среды сборки и окончаний строк.
