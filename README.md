# Thaumcraft 4: Reforged — DOP

Неофициальная доработанная версия **Thaumcraft 4: Reforged** для **Minecraft 1.21.1 / NeoForge**.

Проект основан на порте [Thaumcraft 4: Reforged от notlikethiss](https://github.com/notlikethiss/thaumcraft-4-reforged). Эта редакция продолжает работу над портом и объединяет собственные исправления и доработки.

## Статус публикации

Репозиторий пока содержит только описание проекта. Исходный код и готовые сборки ещё не опубликованы. Подробный список изменений будет подготовлен после сравнения исходной версии порта с текущей редакцией.
