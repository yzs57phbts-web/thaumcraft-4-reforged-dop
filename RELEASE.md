# 1.0.1

Minecraft 1.21.1 / NeoForge 21.1.256+ / Java 21.

## Пофиксили

- Голодный узел получает аспекты съеденных предметов, включая бонусные и содержащиеся аспекты; сохранены счёт одного предмета в стаке, восстановление запаса и исходный шанс роста ёмкости.
- Эльдрический портал открывается с первого корректного нажатия жезлом при готовом лабиринте.

## Адаптировали

- Фильтр заражённых земель находится в самом T4; bbtt-fixes для него не нужен.
- Проверены вкладка T4, жезлы и перезагрузка ресурсов с аддонами; целевые серверные тесты покрывают питание узла, NBT, преобразование и сценарий Witchery с исправленным Dungeon Gear Rules 1.0.7.

## Изменили

- Составные аспекты пищи сохраняются до преобразования узла в заряженный, где раскладываются для CV.
- В заражённых землях исключены Stoneling, Toretoise и пехи; пехи магического леса сохранены.
- Номер релиза и файла — 1.0.1; внутренний номер сохранён ради совместимости с существующими аддонами.

Все изменения относительно авторского порта перечислены в README. Для сборок с Dungeon Gear Rules требуется его исправление 1.0.7: падение на пустой таблице лута относится к этому отдельному моду.
