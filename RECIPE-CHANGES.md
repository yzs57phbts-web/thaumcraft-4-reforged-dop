# Рецепты 1.0.3

Перенесены 5 сохранённых проектов редактора. Исходные ключи, исследования,
ингредиенты, данные результата, аспекты и нестабильность сохранены.
Существующие страницы и ключи исследований сохранены. Отключённые настройками
рецепты не включаются заново. Два проекта кинетического пояса одинаковы по составу
и стоимости; оба ключа сохранены в соответствии с проектами.
Если рецепт ссылается на другой аддон, он включается только при его наличии;
без него сохраняется родной рецепт.

Проверка Minecraft 1.21.1 / NeoForge 21.1.264: все 30 проектов проверены против
живого реестра, включая существование предметов и тегов, родной выбор рецептов
верстака, матрицы и тигля, результаты и раскладки инфузий. Сверены 592
неизменённых runtime-рецептов; полный набор ключей сохранён. Отдельно проверен
Thaumcraft без шести аддонов. Это адресная проверка рецептов, не полное прохождение
Survival, расхода энергии в каждой машине или визуальный аудит всех страниц.

Обычная сборка исходников: Gradle/JDK 21. Для воспроизведения адресной упаковки
выпуска используйте `python tools/package_recipe_release.py --baseline OLD.jar
--classpath NEOFORGE_DEV_CLASSPATH --javac /path/to/javac` (одной командой).
Скрипт проверяет SHA256 прежнего публичного JAR и компилирует только перечисленные
в `tools/recipe-release.json` исходники. Остальные записи архива сохраняются
побайтно. Упаковка ZIP при другой версии Python/zlib может отличаться, как и байты
компиляции при другом JDK; семантика рецептов задаётся Java и проектами JSON.
